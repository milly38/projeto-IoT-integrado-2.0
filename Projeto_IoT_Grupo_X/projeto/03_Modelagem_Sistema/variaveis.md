# VARIÁVEIS DO SISTEMA

## temperatura
Armazena o valor de temperatura obtido pelo sensor DHT11.

---

## umidade
Armazena o valor de umidade obtido pelo sensor DHT11.

---

## rotacao
Armazena o valor de rotação lido pelo potenciômetro/sensor.

---

## estado
Representa o estado atual do sistema.

Possíveis estados:
- NORMAL
- ALERTA
- CRÍTICO
- MANUAL
