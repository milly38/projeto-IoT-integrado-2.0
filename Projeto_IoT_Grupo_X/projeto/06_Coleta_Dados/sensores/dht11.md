# Sensor DHT11

## Função
Responsável por medir temperatura e umidade do ambiente.

---

## Tipo
Sensor digital

---

## Conexão no ESP8266
- VCC → 3.3V  
- GND → GND  
- DATA → D4 (GPIO2)

---

## Uso no projeto
Principal sensor do sistema IoT, enviando dados para a API Flask.

---

## Importância
Base do monitoramento ambiental do sistema.
