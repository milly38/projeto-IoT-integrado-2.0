# LEDs Indicadores

## Função
Os LEDs são utilizados para indicar o estado do sistema.

---

## Tipos de indicação
- LED 1 → Sistema ativo
- LED 2 → Status de envio de dados

---

## Conexão no ESP8266
- LED1 → D1 (GPIO5)
- LED2 → D0 (GPIO16)

---

## Uso no projeto
Indicação visual do funcionamento do sistema IoT.

---

## Importância
Facilita o monitoramento do estado do sistema sem necessidade de serial monitor.
