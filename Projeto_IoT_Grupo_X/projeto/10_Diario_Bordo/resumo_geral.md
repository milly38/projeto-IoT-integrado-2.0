# Resumo do Diário de Bordo

## Conclusão do projeto
O sistema IoT foi desenvolvido com sucesso, integrando hardware (ESP8266), sensores, API Flask e banco de dados.

## Tecnologias utilizadas
- ESP8266
- Python Flask
- MySQL
- JSON
- TCP/IP

## Resultado final
Sistema funcional de monitoramento industrial com envio de dados em tempo real.
