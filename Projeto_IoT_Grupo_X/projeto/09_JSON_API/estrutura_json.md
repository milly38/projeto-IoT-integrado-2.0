# ESTRUTURA JSON

## Objetivo

Organizar os dados enviados pelo ESP8266 em formato JSON.

---

## Exemplo

{
  "temperatura": 28,
  "umidade": 60,
  "rotacao": 120,
  "estado": "NORMAL"
}

---

## Funcionamento

Os sensores realizam leituras e os dados são estruturados em JSON antes do envio pela rede.

---

## Importância

O JSON facilita:
- comunicação entre sistemas
- integração com APIs
- armazenamento
- organização das informações
